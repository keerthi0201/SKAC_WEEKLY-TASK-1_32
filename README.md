# Personal Portfolio Website

A responsive personal portfolio website built using HTML and CSS to showcase my skills, projects, and interest in UI/UX design and frontend development.

---

## Overview

This project is a personal portfolio website designed with a clean black and red theme. It contains multiple pages including Home, About, Skills, and Projects, and is fully responsive for desktop and mobile devices.

---

## Features

* Clean and modern user interface
* Responsive design for desktop and mobile
* Separate pages for Home, About, Skills, and Projects
* Two-column layout for Skills and Projects sections
* Social media profile links (GitHub and LinkedIn)
* Mobile-friendly navigation menu

---

## Technologies Used

* HTML5
* CSS3 (Flexbox and Grid)
* Google Fonts (Poppins)
* Font Awesome Icons

1. Download or clone this repository.
